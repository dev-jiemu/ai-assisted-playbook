# Test-Driven Feature Development

구현 전에 테스트를 먼저 작성하여 명확하고 안전하게 기능을 개발합니다.

## 수행 절차

1. **기능 명세 파악**:
    - 구현하려는 기능의 입출력 조건과 예외 시나리오를 정의합니다.

2. **실패하는 테스트 작성 (Red)**:
    - 프로덕션 코드를 건드리지 않고, 요구사항을 검증하는 테스트 코드를 먼저 작성합니다.
    - 테스트를 실행하여 기대한 대로 실패하는지 확인합니다.

3. **최소 구현 (Green)**:
    - 테스트를 통과시키는 데 필요한 가장 단순한 최소한의 코드만 작성합니다.
    - 테스트를 실행하여 통과함을 확인합니다.

4. **리팩토링**:
    - 테스트가 통과하는 상태를 유지하면서 가독성 개선, 중복 제거, 네이밍 정리를 수행합니다.
